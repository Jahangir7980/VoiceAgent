# Voice Agent (Android)

এটা মুখে বলা কমান্ডে Android ফোন চালানোর অ্যাপ। অ্যাপ খুলতে পারে, কল করতে পারে, যেকোনো বক্সে লিখতে পারে, Next/Send-এর মতো বাটনে চাপ দিতে পারে, কিছু সিলেক্ট করতে পারে আর স্ক্রল করতে পারে। "মাথা" হিসেবে Google Gemini API ব্যবহার করে।

## APK ডাউনলোড
এই রিপোজিটরির **Releases** অংশে সবসময় সর্বশেষ `VoiceAgent.apk` পাওয়া যাবে। কোডে প্রতিবার পরিবর্তন হলে GitHub Actions নিজে থেকেই নতুন APK বানিয়ে দেয়।

## সেটআপ
1. APK ইনস্টল করুন। দরকার হলে "Install unknown apps" অনুমতি দিন।
2. অ্যাপ খুলে **ধাপ ১**-এ গিয়ে অনুমতি দিন।
3. **ধাপ ২**-এ Accessibility খুলে "Voice Agent সহকারী" চালু করুন।
   যদি সুইচটা ধূসর দেখায়: অ্যাপ ইনফো → ⋮ → *Allow restricted settings* চাপুন, তারপর আবার চেষ্টা করুন।
4. **ধাপ ৩**-এ Gemini API key পেস্ট করে সেভ করুন। key নেবেন https://aistudio.google.com/apikey থেকে।
5. স্ক্রিনে নীল 🎤 বাটন দেখা যাবে। চাপ দিয়ে কথা বলুন। কাজ থামাতে বাটনে লম্বা চাপ দিন।

## কীভাবে কাজ করে
- কথা শোনে Google ভয়েস টাইপিং, উত্তর পড়ে শোনায় ফোনের Text-to-Speech। এ দুটো ফ্রি।
- সহজ কমান্ড (অ্যাপ খোলা, ব্যাক, হোম, স্ক্রল, কন্ট্যাক্টকে কল) ফোনেই চলে, Gemini লাগে না।
- বাকি কাজে স্ক্রিনের বাটন ও লেখার তালিকা (আর চাইলে স্ক্রিনশট) Gemini-তে পাঠানো হয়। Gemini ঠিক করে কী করতে হবে, তারপর Accessibility Service সেই কাজটা করে।
- জরুরি নম্বরে (112/100) Android কোনো অ্যাপকে নিজে থেকে কল করতে দেয় না। তাই অ্যাপ নম্বরটা ডায়াল করে রাখে, আপনি শুধু কল বাটনে চাপ দেবেন।
